# Code of Conduct

## Our Standard

Contributors and maintainers must communicate professionally and respectfully.
Technical disagreement is expected; harassment, personal attacks,
discrimination, threats, and deliberate disruption are not acceptable.

Examples of constructive participation include:

- focusing criticism on code, behavior, evidence, and tradeoffs;
- respecting different experience levels and backgrounds;
- accepting correction and updating claims when evidence changes;
- protecting private information disclosed in bug or security reports.

## Enforcement

Report unacceptable behavior privately through the repository owner's GitHub
profile. Maintainers may edit, hide, or remove contributions and may
temporarily or permanently restrict participation when necessary.

This code of conduct applies in repository issues, pull requests, reviews,
discussions, and other project-managed spaces.
