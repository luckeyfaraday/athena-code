# Support

Use the appropriate GitHub channel:

- [Bug report](https://github.com/luckeyfaraday/athena-code/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/luckeyfaraday/athena-code/issues/new?template=feature_request.yml)
- [Documentation issue](https://github.com/luckeyfaraday/athena-code/issues/new?template=documentation.yml)
- [Security report](SECURITY.md)

Before opening an issue, include the output of:

```bash
athena-code --version
uname -a
```

Athena Code publishes native builds for Linux, macOS, and Windows on x64 and
ARM64. Include the exact operating system and architecture in platform-specific
reports. macOS and Windows releases are currently unsigned.
